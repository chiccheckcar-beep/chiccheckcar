# ChicCheckCar

האתר המלא, כמו שהוא באוויר היום, מוכן לפתיחה ב-Claude Code.

## איך מתחילים ב-Claude Code
1. מחלצים את הקובץ לתיקייה במחשב.
2. פותחים טרמינל בתיקייה `chiccheckcar` ומריצים `claude`.
3. Claude Code קורא לבד את `CLAUDE.md` ומבין את מבנה האתר, את הכללים שלך ואת מה שנשאר לעשות.

## לראות את האתר במחשב
```
cd site
python3 -m http.server 8080
```
ואז לפתוח בדפדפן: http://localhost:8080

## מה חשוב לדעת
האתר עובד במלואו, אבל השמירה של לידים במרכז הלידים הייתה מחוברת למערכת של Claude.
מחוץ ל-Claude צריך לחבר אותה למסד נתונים (למשל Firebase). זו המשימה הראשונה ב-`CLAUDE.md`,
ואחריה כל ליד מכל לקוח יגיע למרכז הלידים, ואפשר יהיה להוסיף אימות SMS וזיהוי רכב לפי לוחית.
